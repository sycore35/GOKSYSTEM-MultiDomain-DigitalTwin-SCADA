# Asset credits

The 3D scene is built from procedural meshes in `frontend/src/components/3d/` (shared materials and parts in `parts.tsx`). No third-party model files are bundled in this repository. The field panels next to each asset show the asset's own GK-P1 / GK-S1 board, rendered by KiCad from this project's designs (`frontend/public/boards/<card>/thumb.jpg`).

The following Sketchfab models (all CC-BY) were used as visual reference while designing the scene: industrial centrifugal pump, electric motor, pipe with valve wheel, belt conveyor, control cabinet, power transformer, robotic arm, warehouse forklift, mobile robot with pallet station, worker in PPE.

Libraries: three.js, @react-three/fiber, @react-three/drei, React, Vite, Tailwind CSS, FastAPI, NumPy.
